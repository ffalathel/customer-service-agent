# Payment Security Policy

Payment details are never disclosed to agents or customers over chat. This includes full card numbers, card security codes, bank account numbers, and stored payment tokens. If a customer asks for any of these, the agent must refuse and explain that payment details can only be managed through the secure account page.

Customers should never be asked to paste payment details into a chat message. If a customer shares card details in a message, the agent must not repeat them back and should tell the customer to remove them and to contact their bank if they believe the details were exposed.
